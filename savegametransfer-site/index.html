SaveGameTransfer
Save data, transferred from one device to the next

Your save files, available on every device.

Create an account, add a folder for each platform you emulate, and upload your ROMs, disc images and save states. Everything is organised by system — NES, SNES, PS1, PS2, GBA and the rest — so when you move to a new phone, handheld or PC, you retrieve the exact file you need in seconds.

1

Create a folder

Name it and select a platform. The folder then recognises which extensions are ROMs and which are save data.

2

Upload your files

Drag in an entire library at once, or select files individually with + Add game. Save files are matched to the correct game by filename.

3

Select a game, attach a state

Select any game and the file picker opens directly on its save slot. Attach as many states as you need.

4

Retrieve it anywhere

Sign in on another device and download the file into your emulator's save directory.

Compatible platforms

Each platform carries its own list of ROM and save extensions, so uploaded files are sorted automatically.

Welcome back

Your folders are exactly where you left them.

Create an account

No email address and no confirmation link. Choose a username to begin.
